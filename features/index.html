The desktop workflow

RJ Jarvis helps you move from a content idea to an organized video and a reviewable publishing package. Its desktop workflow keeps you involved at each decision.

Tools for the full content cycle

Each part supports a specific step. Preparing content does not authorize a platform upload.

PLAN

Content calendar

Create a multi-day plan with distinct topics, formats, target platforms and planned dates. Review the pieces before selecting one to make.

CREATE

Video production

Turn a selected piece into a video using the existing content workflow. Keep the resulting MP4 in your desktop workspace.

ORGANIZE

Track every piece

Follow a piece from planned idea to ready video, approval, prepared package and platform processing status.

REVIEW

Publishing package

Check the selected MP4, title, caption, hashtags, destination platform and scheduled date in one place.

CONTROL

Human approval

Approval to prepare is distinct from confirmation to upload. A prepared package does not publish itself.

LOCAL

Desktop-first storage

Plans, video outputs and publishing records are kept on your device until you choose to send content to a platform.

Publishing control

Two clear decisions before TikTok receives a file.

The current test mode is private only. The planned date is saved locally; it does not trigger an automatic upload.

01

Approve the content

You review the generated MP4 and approve the social media item. RJ Jarvis then validates the file and builds a publishing package.

02

Review the destination

When you request a TikTok publication, RJ Jarvis shows the account, caption, privacy choice, video file and local schedule. This step does not upload.

03

Confirm the upload

A separate confirmation initiates the private test upload. RJ Jarvis records a publishing ID and lets you check processing status. It does not retry an upload blindly.

TikTok integration

Official access, explained.

RJ Jarvis uses TikTok Login Kit for OAuth authorization and the official Content Posting API for a confirmed video upload. It requests user.info.basic to identify the authorized account and video.publish for the posting workflow.

It does not ask for your TikTok password. OAuth tokens are stored in your local desktop environment. Before a test upload, RJ Jarvis queries the account's available settings and requires your explicit confirmation.

The current integration fixes the privacy setting to SELF_ONLY. Public posting is not enabled in this version.

What is connected today?

TikTok is the only platform with a test publishing adapter. RJ Jarvis can organize packages for Facebook Reels, Instagram Reels, YouTube Shorts and YouTube, but does not upload to those services in this version.

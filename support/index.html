Frequently asked questions

Common questions

The answers below describe the current desktop test integration.

How do I connect a TikTok account?

The app operator configures an official TikTok developer app. You then complete TikTok's OAuth authorization in your browser. RJ Jarvis never asks for your TikTok password. Connection requires the approved user.info.basic and video.publish scopes.

What does TikTok authorization allow?

user.info.basic lets RJ Jarvis identify the authorized creator account. video.publish enables the Content Posting API workflow when you explicitly confirm an upload. Authorization alone does not upload a video.

Will RJ Jarvis post a video as soon as it is created?

No. You must review and approve the content, prepare a publishing package, request a posting preview and issue a separate confirmation. The current TikTok test mode uses SELF_ONLY privacy.

What does a scheduled date do?

RJ Jarvis saves the planned date locally. It does not run an automatic upload at that time. A confirmed TikTok test upload begins when you give the confirmation.

How can I revoke TikTok access?

Remove RJ Jarvis from your TikTok account's connected-app settings, then delete the local TikTok OAuth token file if you also want to clear credentials from your device. See the Privacy Policy for local data controls.

Why did an upload fail or stay in processing?

Check the publishing status in RJ Jarvis and the error recorded for the item. TikTok may reject a file, account permission or API request, or continue processing after upload. If a publishing ID exists, check its remote status; avoid initiating another upload blindly.

Are Facebook, Instagram and YouTube uploads available?

RJ Jarvis can prepare content packages for those destinations. Their publishing API integrations are not connected in this version.
